# Tic-Tac-Toe (Python)

A command-line Tic-Tac-Toe game built with Python. The project focuses on implementing core Python concepts, including functions, loops, conditional statements, lists, dictionaries, input validation, and game logic.

## Features

- Two-player gameplay
- Choice of X or O
- Win detection
- Draw detection
- Input validation
- Prevention of overwriting occupied positions
- Option to play multiple matches
- Keyboard-based controls using **Q, W, E, A, S, D, Z, X, C**

## Controls

```
 Q | W | E
-----------
 A | S | D
-----------
 Z | X | C
```

Press the corresponding key to place your mark on the board.

## Requirements

- Python 3.x

## Running the Project

Clone the repository:

```bash
git clone https://github.com/dewansh-codes/tic-tac-toe-python.git
```

Navigate to the project directory:

```bash
cd tic-tac-toe-python
```

Run the program:

```bash
python tic_tac_toe.py
```
